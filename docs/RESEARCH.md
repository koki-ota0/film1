### 同じオーナーの関連リポジトリから読み取れる運用パターン

同オーナーの `koki-ota0/game3` PR #1（"ゲーム2本目「ドミノ、つないでください」を公開 + 毎日リリースの土台"）には、N.K. Works の公開情報を調査した要約が含まれていた。そこから、このリポジトリにも転用できる要点は以下。

| 要素 | N.K. Works系のパターン | EigaKitでの置き換え |
|---|---|---|
| 成果物の単位 | 1ゲーム = 1つの完結したブラウザ体験 | 1アプリ = 1つの完結したテンプレ作成ツール |
| 公開の速さ | push即公開に近い運用 | main push → GitHub Actions → Pages デプロイ |
| メタデータ | `games.json` が一覧・SEO・生成の元データ | `apps.json` が一覧・SEO・生成の元データ |
| 生成 | buildスクリプトで一覧/説明/sitemapを生成 | `tools/build.js` で同様に生成 |
| 品質ゲート | checkスクリプトで公開前確認 | `tools/check.js` |
| 新規作成 | 雛形生成コマンド | `npm run new -- <slug> "タイトル" "キャッチ"` |
| シェア導線 | OGP/シェア文/作者導線を各ページに入れる | 各アプリにホーム導線 + Xシェアボタン + 画像書き出し |
| 日々の改善 | 出してから小さく直す | テンプレの文言・見た目・書き出しサイズを反応見て改善 |

### この方式が強い理由

1. **作る単位が小さい**: 「1日1本」を成立させるには、1本のスコープを極端に小さくする必要がある。
2. **公開コストが低い**: 一覧・サイトマップ・OGPなどを手作業にしない。
3. **シェア前提の出力**: 体験そのものより「Xに貼れる結果」があると拡散されやすい。
4. **失敗しても次を出せる**: 1本が当たらなくても、翌日に別の型を出せる。

## 2. 映画Xユーザー向けテンプレ調査

### 調査で見えた需要

Web検索・既存サービスの観察から、映画系で繰り返し使われるフォーマットは次の通り。

| テンプレ | なぜ強い | Xでの拡散理由 | 今回の実装 |
|---|---|---|---|
| 好きな映画4選 / Top 4 | Letterboxd文化と相性がよく、自己紹介になる | 1枚で人格が伝わる。引用RTで真似されやすい | ✅ `app/top4` |
| 映画ティア表 | 好みの差が出て議論になる | 賛否がコメントを生む。テンプレとして再利用される | ✅ `app/tier` |
| 今月/今年のベスト映画ランキング | 時期イベント（年末・月末）に強い | 「自分もやろう」が起きやすい | ✅ `app/ranking` |
| 映画感想カード | 観た直後に出しやすい | 1作品レビューとして軽く投稿できる | 次候補 |
| 映画自己紹介カード | 新しい映画垢の初投稿に使いやすい | プロフ代わりに固定しやすい | 次候補 |
| 監督/俳優別ベスト3 | 推し語りに強い | ファンコミュニティ内で回りやすい | 次候補 |
| 「今週観た映画」ログ | 継続投稿の習慣化 | 定期フォーマット化しやすい | 次候補 |

### 既存サービスの観察

- **TierMaker / tier系ツール**: ティア表需要は強いが、映画X特化・日本語UI・スマホ最適化・そのままX投稿導線は弱いものが多い。
- **top4系ツール**: Letterboxd Top 4ポスター需要は明確。日本語文脈（「好きな映画4選で自己紹介」）に寄せる余地がある。
- **プロフメーカー系**: 映画好き自己紹介テンプレ需要あり。ただし画像編集自由度や映画特化の見栄えに改善余地。

### EigaKitで狙う差別化

1. **映画X投稿に特化**: 汎用ティア表ではなく、映画投稿の文脈に合わせる。
2. **スマホで1分**: 観終わった直後に作れる。
3. **端末内完結**: 画像アップロードもブラウザ内処理。ログイン不要。
4. **書き出しが主役**: 「作れる」より「Xに貼れる画像がきれい」を優先。
5. **同じリポジトリで量産**: `apps.json` に1件足して `site/<slug>/index.html` を作れば増やせる。

## 4. 次に足すと伸びやすいもの

1. **映画感想カード** — 1作品の感想・評価・一言を画像化。観た直後の投稿に強い。
2. **映画自己紹介テンプレ** — 「好きなジャンル / 推し監督 / 最近刺さった映画」など。
3. **今月観た映画ログ** — 月末の定期投稿フォーマット。
4. **OGP自動生成の改善** — アプリごとの固有OGP画像をbuild時に用意。
5. **共有テキストの最適化** — ハッシュタグ・定型文をアプリごとにABテスト。
6. **作品検索補助** — TMDB等のAPIキー運用方針を決めた上で、ポスター検索を任意機能化。
